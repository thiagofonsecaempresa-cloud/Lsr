NOVO NESTA VERSÃO
- Tela Qualidade e Ocorrências para registrar peças manchadas, rasgadas, descosturadas, desbotadas, encardidas, com odor persistente, desgaste ou outro defeito.
- Registro de data, peça, quantidade, etapa de identificação, providência, situação, responsável e observações.
- Histórico filtrável por situação e peça, resumo de ocorrências abertas, peças aguardando solução, recuperadas e descartadas.
- Exportação CSV das ocorrências e nova aba Qualidade na exportação Excel.
- A ocorrência não altera automaticamente o inventário. Ao recuperar ou descartar uma peça, atualize também a contagem física para não criar divergência de estoque.
- O inventário recomenda registrar defeitos individualmente na tela Qualidade.

PUBLICAÇÃO
Envie os três arquivos principais para a raiz do repositório GitHub Pages. O arquivo principal deve se chamar index.html.

EXPORTAÇÕES
Excel (.xlsx) com abas formatadas; CSV de produção, inventário e qualidade; backup JSON e pacote de análise JSON. A geração do .xlsx é feita no próprio JavaScript, sem biblioteca externa.

DADOS
Os registros são salvos no armazenamento local do navegador. Faça um backup JSON antes de substituir os arquivos no GitHub Pages.


Atualização da produção diária: o lançamento agora é feito em lote. Selecione data, responsável/equipe e etapa uma vez, preencha as quantidades de todos os tipos de peça na mesma tela e informe o tempo total do lote. O histórico agrupa as peças do lote e permite excluir o lote inteiro.
